1. What is computed property syntax in JavaScript (ES6), and how does it improve object creation compared to pre-ES6 patterns?

**Deep explanation:** Introduced in ECMAScript 2015 (ES6), computed property names allow developers to dynamically evaluate an expression as an object property key directly inside an object literal using square brackets: `const obj = { [expression]: value }`. Prior to ES6, object literal keys had to be static identifiers or string literals. Setting dynamic keys required an imperative two-step workflow: first instantiating the object, and then mutating it on subsequent lines using bracket notation (e.g., `var obj = {}; obj[key] = value;`). Computed property syntax makes dynamic object construction declarative and concise, enabling inline key evaluation inside object literals, object return statements, and object destructuring defaults. Any valid JavaScript expression can be placed inside the brackets, including variables, template literals, arithmetic operations, and function calls.

**Interview answer:** "Computed property syntax allows dynamic expressions to be evaluated as object keys directly inside an object literal using square brackets. This replaces the imperative pre-ES6 pattern of initializing an object first and then mutating it with bracket notation on subsequent lines."
